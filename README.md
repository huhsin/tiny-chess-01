# tiny-chess-01

A chess engine in at most 4,096 bytes of Python, entered in
[make.fun bounty tiny-chess-01](https://make.fun/bounty/tiny-chess-01):
Build the strongest chess engine in 4 KB of Python ($500).

[![tiny-chess-01](https://make.fun/bounty/tiny-chess-01/badge.svg)](https://make.fun/bounty/tiny-chess-01)

`main.py` is the whole engine: pure Python standard library, no other files,
no data outside its own bytes. It plays the make.fun house gauntlet through
the environment routes described in the bounty's rules.
